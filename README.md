# duan rA — Galerie d'Art Numérique

**Pulchritudo sine fine** — Beauté sans fin

Site vitrine de galeries d'art numérique contemporain. Explorez des collections d'œuvres d'art visuel et une installation audiovisuelle générative immersive.

## 🎨 Fonctionnalités

- Mode sombre/clair persistant
- Galeries avec navigation par onglets
- Installation audiovisuelle générative en modal
- Accessibilité complète (ARIA labels, lecteur d'écran)
- Protection contre le téléchargement/copie des images
- Optimisation SEO avec métadonnées structurées
- Images optimisées en WebP

## 🛠️ Technologies

HTML5 · CSS3 · JavaScript · GitHub Pages
